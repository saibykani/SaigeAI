Saige AI · extension settings

Create a token in Saige → Automation & Privacy → Browser extension. It only lets this extension score and save jobs, build resumes, draft emails and read your prepared answers, and you can revoke it any time.

v2: on LinkedIn, Naukri, Indeed, Greenhouse, Lever, Ashby and Workday a green Saige pill appears when a job is on screen (on LinkedIn, hiring posts get a button too). Press Ctrl+Shift+S on any page, or use Scan this page in the popup. Saige reads only the page you are viewing, never sends email, and never presses Submit. Change the shortcut at chrome://extensions/shortcuts.
